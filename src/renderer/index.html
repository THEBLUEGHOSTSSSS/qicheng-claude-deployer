快速填写

在 VS Code 中开始

  1. 1

    打开一个工作文件夹

  2. 2

    打开 Claude 面板

    点击 Claude 图标，或在命令面板搜索 Claude Code。保存配置后，请先重启 VS Code。

    完成第一次对话

    可以先问“请说明你可以如何帮助我”。第三方服务若仍提示登录，请检查 Disable Login Prompt 设置。
