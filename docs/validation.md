# 当前验证范围

公开版本：`0.1.0-alpha.1`。首版核心基线于 2026-10-30 检查，公开发布准备于 2026-10-31 进行。

## 已有证据

| 层次 | 检查 | 范围 |
| --- | --- | --- |
| 核心逻辑 | `npm test`，26 个用例 | 临时目录配置合并与恢复、后续修改保护、损坏文件与链接拒绝、认证冲突、秘密字段隐藏、协议编码、错误响应与下载摘要 |
| 静态约束 | `python3 -m unittest tests.check_renderer -v`，2 个用例 | 标签、CSP、本地资源、JS 语法、禁用页面存储/Node 调用、减少动效 |
| 桌面 UI | `npm run test:ui` | macOS 真实 Electron 预览窗口、导航、隔离、预览拒绝操作、窄窗口布局 |
| 模拟流程 | 同一 UI 脚本中的隔离测试宿主 | 配置预览门槛、输入修改后失效、清空密钥、错误显示；没有真实 Windows 安装 |

测试使用假密钥和模拟服务响应。源码、构建内容和人工界面检查没有使用真实账户测试模型请求。

## 未完成的目标验证

- Windows 10/11 真机解压、启动和系统检测。
- WinGet/MSI 权限提示、组件安装结束后的实际状态。
- CC Switch 安装、协议注册、确认导入和手动启用。
- 用户服务账户的短文本请求、VS Code 实际对话和工具调用。

组件存在、安装器退出成功、HTTP 200 和短请求通过分别只证明对应步骤，不能替代完整客户端验收。欢迎贡献目标机实测结果，说明系统版本、架构、组件版本、实际步骤与已脱敏证据。

## 如何复查发布包

Releases 中提供 `*.zip.sha256`。Windows PowerShell 可执行：

```powershell
Get-FileHash .\Qicheng-Deployer-0.1.0-alpha.1-Windows-x64-Portable.zip -Algorithm SHA256
```

将输出与下载的摘要文件比较。包内 `SHA256SUMS.txt` 列出应用与说明文件摘要；发布页另附 `delivery-manifest.json`，记录 ZIP 大小、检查数量与 Windows 运行状态。摘要可发现传输损坏，不等同于发布者签名或安全审计。
