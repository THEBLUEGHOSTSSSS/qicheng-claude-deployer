# 快速上手

本包用于 Windows 10/11 x64。它帮助安装和配置 Claude Code，图形对话在 VS Code 的 Claude 面板中进行。

## 开始前

1. 把整个 ZIP 解压到一个普通文件夹，例如桌面上的“启程部署器”。
2. 双击 `Qicheng Deployer.exe`。无需另外安装 Node.js 或 Python。
3. 这是尚未完成 Windows 真机验收的开发试用版，应用本身没有单独的发布者代码签名。如果系统阻止运行，请保留提示给维护者核对来源，不要关闭系统保护。
4. 准备服务商提供的 API 地址、API Key 和模型 ID。不要把密钥发进群或截图中。使用官方账户登录的人也可跳过 API 配置，在 VS Code 中走官方登录。

## 四步使用

**1. 环境检查**：打开后自动检查。显示“待安装”表示没有找到组件；显示“待确认”表示检测没有得到可靠结果。便携版、自定义安装目录或企业策略可能需要人工核实。

**2. 安装组件**：按项安装 Claude Code、VS Code、官方 Claude 扩展；推荐装 Git。CC Switch 为可选服务管理工具。每项会弹出确认，安装期间保持窗口打开，并处理系统权限提示。没有 WinGet 时，在 Microsoft Store 更新“应用安装程序”。

**3. 连接模型**：第三方服务选择对应模板或自定义，填好 API 基址、认证类型、密钥。API 基址不要带 `/v1` 或 `/messages`。RayinAPI 模板来自其文档的 `https://www.rayinai.com`，如控制台给了其他地址，以该账户实际说明为准。

点击“预览修改”，检查后点“备份并保存”。保存成功会清空页面密钥框；如需测试或导入 CC Switch，请重新粘贴密钥。请在保存前退出其他可能写配置的 Claude/CC Switch 窗口。

CC Switch 使用：先安装，再点击“导入 CC Switch”。系统链接包含密钥，只用于本机打开导入窗口；不要复制分享。必须在 CC Switch 中确认导入，之后按需要启用。导入动作本身不表示服务已激活；重复导入可能产生副本。官方 API Key 模式请直接保存，或在 CC Switch 内使用官方预设；首版不把该模式改写成 Bearer Token。

**4. 验证与使用**：填写服务商实际支持的模型 ID，再点击“发送一次测试”。这会向你填写的服务商发送固定短文本，最多生成 16 token，可能扣除少量额度。测试不会发送本地文件，也不会自动重试。

随后打开 VS Code，打开一个工作文件夹，点击 Claude 图标开始对话。保存配置后需要重启 VS Code。使用第三方服务但仍提示登录时，点击部署器的“打开登录提示设置”，在 VS Code 中勾选 `Disable Login Prompt`，再重新加载窗口。

## 出现问题

| 提示 | 处理 |
| --- | --- |
| 已安装但版本检查失败 | 先从开始菜单打开软件，记录具体错误；不要反复重复安装 |
| 401 | 核对密钥、认证方式、该密钥是否已失效 |
| 403 | 核对账户/模型权限、服务商限制和网络 |
| 404 | 核对 API 基址与模型 ID，不要把文档网址填作 API |
| 429 | 检查控制台额度或请求频率 |
| 连接失败或超时 | 检查网络和原有代理；部署器不会修改代理或关闭证书校验 |
| HTTP 成功但格式不符 | 可能访问了网页、登录页或不兼容的接口，不能视为模型可用 |
| 原 JSON 损坏 / 自定义目录 / 认证助手 | 部署器停止写入；保留原配置，交维护者定位 |
| 当前配置已被修改，恢复被停止 | 防止覆盖后续改动；从备份人工合并 |

点击“导出诊断报告”，把 JSON 与具体错误描述交给维护者。报告不包含密钥和配置内容；请另外提供 Windows 版本、操作步骤，以及遮盖密钥后的错误截图。

## 恢复与保留

“恢复最近一次配置”可以恢复部署器保存前的版本；如保存前没有配置文件，会移除本次创建的文件。只处理 `~/.claude/settings.json`，不卸载软件。

备份目录是 `%USERPROFILE%\.claude\qicheng-backups`。其中可能包含密钥，不要公开或当成诊断报告发送。部署器不自动清理备份。完整关闭部署器后，删除其解压目录即可移除部署器本身；已安装的软件和 Claude 配置不会因此消失。
